
# Zomato Customer & Restaurant Insights Analysis

## Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on the Zomato restaurant dataset to uncover insights related to customer behavior, restaurant trends, ratings, and ordering patterns. The analysis helps understand how different restaurant categories perform and how customer preferences vary between online and offline orders.

The project was developed using Python libraries for data cleaning, analysis, and visualization.

---

## Objectives
- Analyze customer ratings across different restaurant categories
- Compare online vs offline ordering trends
- Identify restaurant types receiving more offline orders
- Determine average spending patterns of couples
- Visualize restaurant trends and customer preferences
- Extract meaningful business insights from raw restaurant data

---
